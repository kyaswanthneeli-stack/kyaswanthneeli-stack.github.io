How it works

01 / Validate

The Python service authenticates callers, validates tool arguments and rejects tools outside its fixed allowlist.

02 / Inspect and redact

Deterministic patterns flag selected instruction overrides. Nested email and secret patterns are redacted before demo adapter execution.

03 / Authorize and account

The backend binds a short-lived, one-use approval to the exact request. A lock enforces a per-session call limit.

04 / Inspect the evidence

The repository includes tests for concurrent limits, approval replay, tampering, expiry and output redaction.
