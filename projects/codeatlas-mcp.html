How it works

01 / Parse locally

The Python service parses source using the built-in AST module. It never imports or executes the inspected source.

02 / Index definitions

SQLite stores definitions, signatures, line ranges and static call candidates. Reindex to update the snapshot.

03 / Query over MCP

Five tools provide indexing, symbol lookup, module summaries, bounded graph queries and potential test impact.

04 / Measure carefully

The repository contains 16 tests and a reproducible 50,000-line synthetic benchmark. Byte reduction is not a measured token-saving claim.
