01 / START HERE

What is it, really?

A coding assistant may need to know which function calls another or which tests could be relevant. Reading many full files creates extra context and noise. A structural index lets the assistant ask smaller, more targeted questions.

IN EVERYDAY LANGUAGE

Think of a large codebase as a city. Before visiting every building, a map shows where roads connect. CodeAtlas makes a map of Python definitions and likely call relationships; it cannot tell you everything inside each building.

05 / OPEN THE EVIDENCE

Show the working parts.

✓ Implemented

  • Indexes Python classes, functions, nested and async definitions.
  • Handles direct-name and some import-alias static call candidates.
  • Offers five local MCP tools and a CLI; queries support edge/depth bounds.
  • Reports possible test callers by walking reverse graph candidates.
  • Has 15 indexing tests and one stdio protocol integration test.

○ Not claimed

  • Python-only; uses standard-library AST rather than Tree-sitter.
  • Static candidates cannot resolve arbitrary runtime dispatch, inheritance, reflection or wildcard imports.
  • An impacted test is a possible caller, not confirmed test coverage.
  • The public graph demo is a fixed fixture; private repositories are not uploaded.
  • Token payload comparisons are real measurements of different information; no agent cost-saving percentage is proven.

06 / QUESTIONS THAT MATTER

Understand the trade-offs.

COMMON QUESTION

Does it read the code?

Yes. It reads eligible Python files while indexing, then returns focused structural summaries for later questions.

COMMON QUESTION

Does it generate answers with an LLM?

No. This repository is an indexing and MCP-tool project; it does not run a language model.

COMMON QUESTION

Are the call graphs exact?

No. The code creates static candidate relationships. Dynamic behavior can produce missed or incorrect edges.

Being clear about limitations is part of engineering: the project shows patterns and testable code, not a promise of production security, measured cost reduction or unconfigured model inference.

07 / KEY WORDS
