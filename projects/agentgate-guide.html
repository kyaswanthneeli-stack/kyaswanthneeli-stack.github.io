AgentGate.

A security checkpoint between an AI agent and its tools. AgentGate is a hosted Python/FastAPI prototype that validates agent tool requests against a small allowlist, checks selected patterns, enforces simple limits, and requires a one-use approval for a sensitive demonstration action.

What is it, really?

An agent with unrestricted tool access could request unexpected actions or leak sensitive text. This prototype puts predictable checks between a request and two fixed demonstration tools.

Receives authenticated tool calls and exposes health and documentation.

Pydantic

HMAC / SHA-256

Regex + Python lock

Handles simple policy patterns, redaction and process-local state.

05 / OPEN THE EVIDENCE

Show the working parts.

✓ Implemented

  • Client and administrator authentication are separated.
  • Only two named demo tools are allowlisted.
  • Approval tokens are request-bound, one-use and time-limited.
  • Redacts selected email/key patterns in nested values and outputs.
  • Hosted /health and /docs are publicly checkable; protected endpoints require credentials.

○ Not claimed

  • The two adapters are simulated; send_notification does not send a real message.
  • Pattern checks are not robust against obfuscated, multilingual or indirect prompt injection.
  • Session counts, approvals and audits live in one server process and reset on restart.
  • The caller selects the session string, so per-session caps are not robust tenant quotas.
  • No general MCP proxy, production security certification or full denied-event audit.

06 / QUESTIONS THAT MATTER

Understand the trade-offs.

COMMON QUESTION

Does it actually send notifications?

No. The notification adapter returns a simulation flag and does not send a message.

COMMON QUESTION

Can I try the live endpoint without a key?

The health endpoint and Swagger documentation are public; protected tool operations correctly reject missing credentials.

COMMON QUESTION

Can it stop every prompt injection attack?

No. It implements a limited set of checks, not a complete agent security system.

Being clear about limitations is part of engineering: the project shows patterns and testable code, not a promise of production security, measured cost reduction or unconfigured model inference.

07 / KEY WORDS

No jargon left behind.

Allowlist
A short list of tool names that the system permits.
Approval token
A short-lived permission tied to one exact tool request.
Redaction
Replacing selected sensitive text with safe placeholders.
Audit metadata
A record of what was allowed without copying raw arguments.
