05 / Professional project walkthroughs

How I approach applied AI.

Architecture-level explanations of professional work. These are experience walkthroughs, not public copies of company repositories.

Knowledge systems / RAG

Enterprise knowledge assistant

Connecting long-form documents to grounded conversational answers through retrieval.

Documents → Chunking → Embeddings → Retrieval → LLM
Explore engineering approach ＋

Document text is prepared and split into retrievable passages. Embeddings and vector search surface relevant content, while a Python/FastAPI backend passes selected context to the response workflow. Important decisions include chunk size, source relevance and selective conversation history.

Technologies: Python, FastAPI, LangGraph, ChromaDB / Milvus, Azure search and LLM APIs.

Professional project overview. No customer documents, source code, accuracy rates or deployment metrics are disclosed.

Agentic workflows / Business data

Product and order search

Orchestrating multi-step questions that need real business records and tool results.

Question → Orchestration → BigQuery / Tools → Answer
Explore engineering approach ＋

A Python backend accepts a user request, routes it through a task workflow, and retrieves product or order information from business systems. Context is carried between steps so later calls can use earlier findings; logging helps investigate failures and unnecessary tool calls.

Technologies: Python, ADK, LangGraph, BigQuery, MCP and LLM integrations.

Illustrative flow based on project experience. No proprietary business data or unverified performance numbers.

Conversational AI / Voice

Voice assistant workflow

Connecting speech recognition, conversational reasoning and spoken responses.

Audio → Transcription → Intent / Tools → Speech
Explore engineering approach ＋

Speech-to-text transcribes requests, a Python backend manages conversational context and approved tool integrations, and text-to-speech produces spoken output. The design balances latency, error recovery and clearly defined tool behavior.

Technologies: Python, FastAPI, speech-to-text, text-to-speech, Azure and agent workflows.

Architectural walkthrough, not a published customer application or live speech service.
